An entry for the [One-Liner Laugh Lab](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae) bounty on make.fun: one short funny line answering a prompt — the excuse a robot vacuum gives after eating a sock.

> I didn't eat your sock. I adopted it. It lives under the couch now and pays rent in lint.

## How it works

`main.ts` (Node) writes the single entry line to `/output/entry.txt` as UTF-8 text. It guards the length (1–200 characters) and throws if the line falls outside the gate.

```sh
node main.ts
```
